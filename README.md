# 角色卡台灣繁中工具 v0.6.2（2026-10-23 更新）

把簡體 SillyTavern 角色卡（PNG／JSON）與 Preset 轉成台灣繁體中文。角色設定、世界書、開場白、正則畫面一起轉換並同步對應；網址、音源、程式名稱維持原樣。全部在瀏覽器處理，不上傳、不需要伺服器程式。

## 使用流程

1. 載入角色卡，按「轉換為台灣繁中」。有設定 AI 時按鈕會變成「一鍵轉成台灣繁中（含 AI 校正）」。
2. 「AI 校正結果」：AI 列出 OpenCC 轉錯的字與大陸用語的台灣說法，可逐條或全部「接受」，接受後也能逐條或全部「恢復原狀」。沒按接受的不會套用。
3. 「需要你確認的詞」：點詞語，選擇全部改、全部保留或逐處決定；可請 AI 判斷。
4. 「搜尋與修正」：輸入姓名或文字，列出所有出現位置，可一次同步更正。
5. 「角色名快捷按鈕」（選用）：點選角色名，下載的卡片會內建酒館助手「輸入助手」腳本的角色名按鈕，聊天時點一下就插入名字。卡片原本已有輸入助手時，只更新其中的角色名按鈕，引號、括號等其他按鈕保留。
6. 「簡繁對照」：每個欄位按行對齊，左邊簡體、右邊繁中，只有一條捲軸；淡色是有變動的字，醒目色是待確認的詞。
7. 技術檢核通過後，從底部下載 PNG 或 JSON。每一步都可以「復原上一步」。

## 維護繁體化詞庫

編輯 `dist/dictionary.json`，存檔後重新整理網頁即生效，不必重建。

- `autoFix`：轉換後一定是錯字的寫法，會自動修正（例如 籤售→簽售、髮現→發現）。
- `review`：可能對也可能錯的詞，只提醒、由使用者決定（例如 冷麵、不準、酒店）。
- `taiwan`：意思明確的台灣用語（例如 屏幕→螢幕）。
- `knownGood`／`aiScanChars`：AI 檢查時略過的正確詞，以及需要 AI 檢查的易錯字。

`find` 預設是純文字，加上 `"regex": true` 才當正規表示式。網頁第 2 步產生的「詞庫建議」可直接貼進對應區塊。檔案格式錯誤時，網頁會改用內建詞庫並顯示提示。

注意：下次更新工具時，新版的 `dist/dictionary.json` 會蓋掉你改過的檔案，更新前請先備份並把自己加的規則併回去。

## AI 協助

使用者自備 API 金鑰（Google Gemini／AI Studio、Anthropic、OpenAI 相容服務）。金鑰只存在使用者自己的瀏覽器（localStorage），不勾「記住」則關閉網頁就消失；網站沒有伺服器接收金鑰。AI 校正時會把卡片裡的中文文字分段送給使用者選的服務商（網址不送，程式碼只送其中的中文和前後少量字元）；單獨判斷某個詞時只送前後約 24 字。AI 只提出建議，由網頁依保護規則替換，使用者按接受才套用。

建議用 Google AI Studio 的免費額度：在沒有綁定帳單的專案另建一把專用金鑰，模型填 `gemini-3.5-flash-lite` 或 `gemini-3.8-flash`，連線網址已內建。免費額度送出的內容可能被 Google 用來改進產品。

## 安全設計

- 角色卡內容一律以純文字顯示，卡片裡的 HTML／JS 不會在本頁執行。
- 頁面設定內容安全政策（CSP）：只載入本站的程式，不載入任何外部腳本。
- 轉換後逐欄比對原卡：網址與媒體路徑、`<script>`／`<style>` 的程式符號、JS 函式與事件名稱、正則語法；任何變動都會阻擋下載。

## 限制

靜態檢查不執行卡片腳本；外部世界書、外掛行為與實際播放仍需在酒館測試。網易雲音樂、QQ 音樂等外鏈音源在台灣常無法播放，工具會在技術檢核中提醒。

## 更新紀錄

### v0.6.2（2026-10-23）
- 改善「搜尋與修正」：輸入轉換前的簡體寫法（例如「季云止」）時，會提示轉換後已變成「季雲止」，並提供「改找『季雲止』」按鈕，帶入後即可同步更正。

### v0.6.1（2026-10-23）
- 修正：AI 偶爾回傳不合理的修正（例如「冷麵 → C」）。修正不是中文、夾雜英數字或長度不對時不採用；有單一詞庫建議就改用詞庫建議，否則留在「需要你確認的詞」由使用者判斷。
- 新增：每條 AI 建議都有「自己改」，輸入想要的寫法後直接套用，可恢復原狀，也會加入詞庫建議。

### v0.6.0（2026-10-23）
- 新增 **AI 一鍵台灣化**：設定 AI 後，轉換時自動請 AI 修正 OpenCC 轉錯的字，並把大陸用語換成台灣說法，列成建議清單；可逐條或全部「接受」，接受後可逐條或全部「恢復原狀」。AI 只提出建議，替換由網頁依保護規則執行，角色名、世界書觸發詞、MVU 變數、網址與程式碼不會被改。
- 新增 **角色名快捷按鈕 × 酒館助手**：自動從世界書與角色設定找出角色名（也可手動新增或請 AI 找），下載的卡片會內建酒館助手「輸入助手」的角色名按鈕，聊天時點一下就把名字插入輸入框，不用記難打的字。卡片原本已有輸入助手時，只更新角色名按鈕，引號、括號等其他按鈕與其他腳本都保留。
- AI 服務商回報請求太頻繁時自動等待重試；每日額度用完時保留已完成的部分。
- 修正：「3.對信息的認知」這類編號文字被誤判成 CSS 名稱，導致技術檢核誤擋。
- 隱私說明更新：AI 校正會把卡片中的中文文字分段送給使用者選的服務商（網址不送，程式碼只送其中的中文）。
